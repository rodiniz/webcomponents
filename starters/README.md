# Starters

Ready-to-run starter templates for @diniz/webcomponents.

All starter source examples use TypeScript: `.ts` for Vanilla and Vue entry points, `.tsx` for React and Next.js components, and `<script setup lang="ts">` in Vue components. The Vite and Next.js build scripts run a typecheck before building.

## Available Starters

- [Vanilla Vite](./vanilla-vite)
- [React Vite](./react-vite)
- [Vue Vite](./vue-vite)
- [Next.js client component](./next-client)

## Run Any Starter

From a starter folder:

```bash
npm install
npm run dev
```
